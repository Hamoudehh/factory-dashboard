# דשבורד ייצור – 4 מכונות

דשבורד למאפייה עם ארבע מכונות: רונדו, קרומסטר, פילו וכנול. הוא מציג KPI למכונות, לעובדים, למוצרים ולמלאי, מאפשר הזנת נתונים ואיפוס, ועובד בנייד ובמחשב.

האפיון המלא נמצא ב-[SPEC.md](SPEC.md).

## הפעלה

**במחשב:** לחיצה כפולה על `index.html`. הגרפים והגופנים נטענים מהאינטרנט, אז בפעם הראשונה צריך חיבור.

**עם שרת מקומי** (מומלץ לפיתוח):
```bash
node tools/serve.js
```
ואז לפתוח את `http://localhost:5173`.

**בנייד:** בונים קובץ אחד ושולחים אותו לטלפון, או פותחים את קישור ה-Artifact ב-claude.ai.
```bash
node tools/bundle.js
```
הפקודה יוצרת את `dist/factory-dashboard.html` (קובץ אחד עם כל הקוד).

## איפה הנתונים

- הנתונים נשמרים ב-`localStorage` של הדפדפן, תחת המפתח `fd.v1`.
- כל מכשיר ודפדפן שומרים נתונים משלהם. כדי להעביר נתונים בין מכשירים: **הגדרות ← גיבוי ושחזור**, מורידים או מעתיקים את הגיבוי במכשיר אחד ומייבאים אותו במכשיר השני.
- בפתיחה הראשונה נטענים 30 ימי נתוני דמו עד היום. את המוצרים, העובדים ופריטי המלאי עורכים בהגדרות.

## הזנת נתונים

במסך **הזנה** יש ארבעה כפתורים:

| כפתור | מה מזינים |
|---|---|
| דיווח ייצור | מכונה, מוצר, משמרת, מתוכנן/תקין/פחת ייצור, השבתות לפי סיבה, עובדים |
| נוכחות משמרת | סטטוס, שעות ושעות נוספות לכל עובד במשמרת |
| תנועת מלאי | כניסה, יציאה או פחת |
| ספירת מלאי | כמות שנספרה מול הכמות במערכת |

אחרי כל שמירה מופיע כפתור **בטל** ל-8 שניות. ברשימת הרשומות האחרונות אפשר למחוק רשומה בשתי לחיצות.

## איפוס

**הגדרות ← איפוס נתונים**. יש שלוש אפשרויות: מחיקת תנועות בלבד, חזרה לנתוני דמו, או איפוס מלא. לפני כל איפוס נשמר גיבוי, ואפשר לשחזר אותו מאותו מסך.

## בדיקות

```bash
node --test
```
הבדיקות מכסות את נוסחאות ה-KPI (OEE, מלאי, ימי כיסוי, עלות עבודה, דיוק ספירה), את נתוני הדמו ואת האיפוס. צריך Node 18 ומעלה.
